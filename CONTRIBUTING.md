# Contribuer à Persillade

- Lire les contrats dans `docs/brainstorm/delivery/` et les règles du dépôt dans `AGENTS.md`.
- Proposer un changement ciblé et exécuter les validations décrites dans le README.
- Avant la première fusion d’une contribution externe, son auteur accepte le CLA dans la
  pull request. Le mainteneur tient à jour le registre des signataires et conserve le lien
  vers l’acceptation. Utiliser le pseudonyme GitHub dans le registre.
